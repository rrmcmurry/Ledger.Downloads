- The License page can now request and install a 30-day trial directly, without requiring a license key or account. Reinstalling Ledger or deleting its local AppData does not restart the trial period, and expired trials retain read-only access to ledger files.
- IT administrators can now automate office-wide Ledger updates with `Ledger.Cli.exe -DownloadUpdatesTo` and `-InstallUpdatesFrom`. One workstation downloads and verifies each release once, while every workstation installs the same verified package from an office-controlled share; the CLI's main help leads with Task Scheduler examples.
- Local development publishes and public installs now use the same `%LOCALAPPDATA%\Ledger\Desktop` application location, and scheduled updates install only strictly newer versions so an older public package cannot overwrite a newer development build.
- Submit Feedback now sends privacy-minimized reports to Ledger's private support inbox from licensed installations, without requiring customers to create a GitHub account. The form explicitly warns against including client information and offers an optional contact email.

### Added

- QuickBooks conversion now inspects selected exports before conversion begins. It immediately warns when an IIF chart contains duplicate subaccount names without unique account numbers and when a Journal CSV appears to hit the known report-export row cutoff.

### Changed

- The installed demo ledger now lives beside the Ledger app and automatically appears in the recent-files list. Ledger no longer places the demo in Documents, and updates preserve an existing installed demo.
- Completed QuickBooks conversions now bring the results and important warnings into view automatically.

### Fixed

- Closing Transaction Detail after drilling down from an Income Statement or other summary report now restores the report's complete period, column, estimated-transaction, filter, and scroll context.
