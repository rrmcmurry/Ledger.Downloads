### Added

- Public installers now include a ready-to-open demo company ledger with a sample chart of accounts and transactions. The installer places it in Documents\Ledger and preserves it during later updates.
- Reclassify Transactions can now filter reference numbers from a pasted Excel list, making bulk cleanup workflows like moving checks out of suspense faster.
- Reclassify Transactions now applies validated batches through one database transaction, making larger bulk cleanup runs much faster while preserving per-transaction validation and audit history.
- QuickBooks conversion now shows separate progress bars for each conversion stage, including list import, transaction import, transaction linking, reconciliation import, and opening the converted ledger.
- QuickBooks conversion now updates the list-import progress bar while accounts, funds, and names are being imported.
- QuickBooks conversion now warns when a CSV export appears to hit the known QuickBooks report export row cutoff and includes the exported transaction date range in that warning.
- Transaction Detail now includes a default Balance column next to Debit and Credit, using real beginning balances for balance-sheet accounts and period activity balances for income-statement accounts.

### Changed

- QuickBooks conversion imports transactions in larger database batches, reducing connection churn and speeding up larger conversion files.
- QuickBooks conversion now imports payroll-heavy files with fewer database round trips, making full-file payroll history conversions significantly faster.
- QuickBooks conversion now compacts the completed setup sections while a conversion is running so stage progress stays visible without extra scrolling.

### Fixed

- Reclassify Transactions now disables apply controls and shows progress feedback while changes are being applied, preventing accidental repeat submissions during longer bulk updates.
- Reclassify Transactions now clears the active filter value box after adding a filter, making repeated paste-and-filter batches faster.
- Transaction Detail no longer fails when showing the new Balance column.
- QuickBooks conversion now skips zero-dollar void transaction shells, including voided paycheck shells, instead of failing the import with empty transaction errors.
- QuickBooks conversion now skips all-zero transaction shells even when QuickBooks does not mark them as voided.
- QuickBooks conversion now preserves legitimate net-zero paycheck headers so advance-repayment paychecks can import as paychecks instead of falling back to general journal entries.
- QuickBooks conversion now keeps the reconciliation-import progress bar at the actual stage progress instead of showing 100% while work is still underway.
