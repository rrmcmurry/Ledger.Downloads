### Added

- General Journal entries now support journal entry numbers and an adjustment flag, with dedicated Adjustment Journal and General Ledger report presets.
- Custom Summary comparisons can show a variance column alongside current and prior-period amounts.
- Reports now use consistent financial-statement headings that clearly distinguish as-of dates from reporting periods.

### Changed

- Journal and adjustment reports now use the more flexible Transaction Detail report experience, including grouping, filtering, drilldown, and matching CSV exports.
- Report printing is more predictable: browser headers and footers start disabled in Ledger Desktop, report content is constrained to printable width, and Working Trial Balance layouts are more compact.
- Report rows default to a compact single-line presentation, with an optional Wrap text control when full descriptions are needed.
- Account add/edit and General Journal workflows now better preserve account identity, including accounts without account numbers, and return users to their prior Chart of Accounts position.
- The retired BankAgent component is no longer included in the customer runtime, and QuickBooks conversion is packaged as an internal adapter rather than a standalone program.

### Fixed

- SimpleFIN cached balances and transaction signs now remain consistent for credit-normal accounts, and Home compares provider balances with the correct cleared, reconciled, and pending Ledger activity.
- Reclassify Transactions now follows the same protected transaction-update rules as the individual transaction editors.
