- Summary reports now reuse one query-option snapshot and one source transaction dataset for arbitrary row/column combinations. Account-balance dates and multi-period Balance Sheets are loaded in set-based batches, reducing the measured annual 2026 monthly Balance Sheet on the active office-testing ledger from about 1.53 seconds to about 0.51 seconds warm and from 75 pre-schema-gating connections to 10.

- Summary reports now link zero amounts to Transaction Detail when the row supports drilldown, making it possible to inspect activity that nets to zero. The new Show Rows control supports All, Active, and Non-Zero (default); Core applies that choice to the completed data matrix before financial-statement headers and subtotals are constructed.

- Office deployment shares now remain bounded: share publishing no longer archives every Desktop build, and the scheduled downloader removes superseded cached installer packages after advancing the verified manifest.

- Account Ledger now lets each user choose 25, 50, or 100 rows per page and remembers that preference on their machine.

- Home now loads substantially faster for large ledger files stored on network shares. Ledger now prepares database schema changes once when an older file is opened instead of repeating that work for every database connection; in testing with a representative network ledger, dashboard loading improved from about eight seconds to under one second.
