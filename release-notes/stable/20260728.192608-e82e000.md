### Added

- Working Trial Balance reports can now hide zero-balance rows while retaining signed-off variance rows, and separately state period Net Income below the balancing totals.
- Reopened signed-off Working Trial Balances now allow workpaper-reference edits without reopening signoff or recapturing balances.

### Changed

- Working Trial Balance printing now uses more natural text and column spacing on portrait pages, preserves longer account names, and uses accounting underlines that distinguish account detail, balancing totals, and separately stated Net Income.
