- Checks marked To Print can now be saved to the batch queue or printed immediately. Direct Print asks for the check number, saves the numbered check outside the queue, and opens its print preview; Print Options opens the existing stock, order, and alignment setup without discarding the check being entered. Check stock is selected with clear side-by-side sheet diagrams instead of a text dropdown.
- Print Checks now has a Close button that returns to the screen it was opened from, including when launched from the File or Vendors menus.
- Check previews now position payee names and mailing addresses appropriately for both check-on-top and check-in-middle stock, preventing addresses from overlapping the written amount.
- Account Ledger now shows transaction reference numbers instead of internal entry IDs and includes a Columns picker for tailoring the ledger view, including an optional transaction Type column.
- Fixed scheduled update downloads failing after the ZIP download because the temporary package was still held open during SHA-256 verification.
