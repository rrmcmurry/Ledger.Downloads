# Ledger Desktop Downloads

This repository hosts public download manifests and release packages for Ledger Desktop.

Ledger Desktop may be installed and used to open `.ledger` files in read-only mode. Editing and saving requires a valid license or trial activation.

Trial keys are not issued automatically yet. During early testing, request a trial key by contacting [rrmcmurry](https://github.com/rrmcmurry) on GitHub.
